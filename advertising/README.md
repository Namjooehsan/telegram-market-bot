# مرکز تبلیغات NOVA و ربات تحلیل بازار

این پوشه همراه با ماژول `advertising/center.py` برای مدیریت کمپین، پیش‌نویس تبلیغ، تأیید مدیر، لینک انتساب و گزارش است. انتشار هر محتوای حمایت‌شده باید از مسیر تأیید انسانی بگذرد.

## موجود در نسخه فعلی
- ساخت پیش‌نویس تبلیغاتی برای بررسی مدیر.
- انتساب ورودی کمپین با لینک شروع اختصاصی.
- ارتباط سفارش موفق با منبع کمپین، در صورت وجود شناسه انتساب.
- گزارش روزانه سفارش‌های پرداخت‌شده و حمایت‌های تأییدشده.
- تنظیم زبان‌ها و سقف پیش‌نویس‌های روزانه از متغیرهای محیطی.

## جایگاه‌های قابل فروش
1. اسپانسر گزارش صبح/ظهر/عصر/شب بازار.
2. جایگاه معرفی ابزار یا خدمت در Mini App با برچسب «تبلیغ».
3. پست حمایت‌شده در کانال‌های خودمان، پس از اتصال و تأیید مقصد.
4. کمپین معرفی خدمات طراحی وب‌سایت، ربات، اپلیکیشن و اتوماسیون.
5. کمپین همکاری در فروش با لینک و کد انتساب منحصربه‌فرد.
6. بسته اسپانسری چندزبانه برای یک دوره زمانی مشخص.

## قواعد کیفیت
- تبلیغ از تحلیل مستقل جدا باشد؛ پرداخت اسپانسر هیچ اثری بر رتبه‌بندی یا سیگنال ندارد.
- ادعای سود تضمینی، بازده تضمینی، تعداد بازدید یا فروش غیرقابل‌اثبات ممنوع است.
- آمار «نمایش»، «کلیک»، «سرنخ»، «سفارش» و «درآمد قطعی» جدا گزارش شوند.
- قبل از انتشار، مالک آگهی، مقصد، متن، لینک، قیمت، بازه زمانی و مجوز استفاده از تصویر/نشان ثبت شود.
- ارسال ناخواسته، پیام انبوه نامرتبط و پنهان‌کردن ماهیت تبلیغ انجام نشود.

## وضعیت انتشار بیرونی
اتصال API Buffer در Railway شناسایی شده است، اما بررسی فهرست کانال‌ها در Buffer، کانال متصل فعالی نشان نداد. بنابراین هنوز انتشار اجتماعی از Buffer تأیید نشده است. مقصدهای تلگرام نیز باید از تنظیمات مجاز ربات و فهرست مدیر بررسی شوند.

این پوشه و ماژول به معنی درآمد محقق‌شده یا فعال بودن همه شبکه‌های تبلیغاتی نیست؛ هر کمپین پس از اتصال مقصد و ثبت پرداخت قابل گزارش است.
