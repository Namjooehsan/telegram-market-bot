# ربات تحلیل بازار و عضویت پریمیوم

ربات بازار، داده‌های تازه بازار اسپات را هنگام ساخت هر گزارش از Binance دریافت می‌کند؛ تحلیل هوش مصنوعی اختیاری است و انتشار گزارش‌ها همچنان فقط پس از تأیید مدیر انجام می‌شود.

## قابلیت‌ها
- گزارش BTC و دارایی‌های قابل تنظیم با قیمت، تغییر ۲۴ساعته، حجم معاملات و وضعیت میانگین متحرک ۲۰ ساعته
- مقایسه حجم آخرین کندل یک‌ساعته با میانگین ۲۴ کندل قبلی؛ این فقط هشدار جهش حجم است و اثبات فعالیت نهنگ نیست
- تحلیل فارسی با OpenAI Responses API در صورت تعریف `OPENAI_API_KEY`
- پرسش تحلیلی `/ask` برای مدیر و اعضای پریمیوم
- هشدار جهش حجم با دستور `/whales`
- زمان‌بندی پیش‌نویس‌ها در ساعت‌های ۰۸:۰۰، ۱۲:۰۰، ۱۶:۰۰ و ۲۱:۰۰ تهران
- تأیید/رد پیش‌نویس از طریق دکمه‌های تلگرام و ذخیره پایدار در SQLite روی volume
- دستورهای `/start`، `/help`، `/plans`، `/pay`، `/paid`، `/draft`، `/status`، `/payments`، `/approvepay` و `/rejectpay`
- فروش اشتراک ۳۰روزه و ایده اختصاصی از طریق فاکتور Telegram Stars با اعتبارسنجی پیش‌پرداخت و ثبت رسید پرداخت
- آزمون بازار، معما، لطیفه، قیمت لحظه‌ای و مرکز فرمان `/menu`
- کاتالوگ `/ideas` با ایده‌های مبتنی بر سیگنال‌های تقاضای بازار جهانی و منابع قابل بررسی
- نقشه بازارهای `/markets` و موتور پژوهش خودکار `/opportunities` و جستجوی زنده `/marketsearch`
- اتصال فقط‌خواندنی به ردیاب ناهنجاری حجم از طریق `/whalestatus` و `/whalealerts`
- ثبت حمایت اختیاری BTC/BCH/XRP/ADA با `/donate` و ارسال TXID با `/tx`؛ اعلان خصوصی برای مدیر و تأیید/رد دستی
- آدرس‌های حمایت BTC/BCH/XRP/ADA از متغیرهای محرمانه Railway؛ حمایت رمزارزی هیچ خدمت دیجیتالی را فعال نمی‌کند

## متغیرهای مهم محیطی
- `TELEGRAM_BOT_TOKEN`: توکن ربات؛ فقط در Railway Variables
- `TELEGRAM_CHAT_IDS`: شناسه کانال و گروه، جداشده با کاما
- `TELEGRAM_ADMIN_IDS`: شناسه عددی مدیر
- `TELEGRAM_WEBHOOK_SECRET`: کلید محرمانه وب‌هوک
- `DRAFT_DB_PATH`: مسیر SQLite روی volume پایدار
- `ENABLE_SCHEDULER=true`: فعال‌سازی زمان‌بندی
- `TRACKED_SYMBOLS`: فهرست جفت‌ارزها، مانند BTCUSDT,ETHUSDT
- `OPENAI_API_KEY`: کلید API خصوصی برای تحلیل هوشمند
- `OPENAI_MODEL`: پیش‌فرض اقتصادی `gpt-6-luna`
- `OPENAI_BASE_URL`: آدرس API سازگار با Responses API؛ فقط از ارائه‌دهنده مجاز استفاده شود
- `AI_DAILY_REQUEST_LIMIT`: سقف کلی فراخوانی هوش مصنوعی در هر روز؛ پیش‌فرض ۱۲ بار برای کنترل هزینه
- `STARS_PREMIUM_PRICE`: قیمت اشتراک ۳۰روزه به واحد Stars؛ صفر یعنی غیرفعال
- `STARS_IDEA_PRICE`: قیمت یک ایده اختصاصی به واحد Stars؛ صفر یعنی غیرفعال
- `STARS_FUNPACK_PRICE`: قیمت بسته سرگرمی و معما به واحد Stars؛ صفر یعنی غیرفعال
- `TELEGRAM_WALLET_BOT_USERNAME`: نام کاربری ربات کیف پول برای بازکردن لینک آن
- `SUPPORT_BTC_ADDRESS`, `SUPPORT_BCH_ADDRESS`, `SUPPORT_XRP_ADDRESS`, `SUPPORT_XRP_TAG`, `SUPPORT_ADA_ADDRESS`: آدرس‌های عمومی حمایت اختیاری؛ فقط در Railway Variables تنظیم شوند
- `WHALE_TRACKER_API_URL`: نشانی عمومی سرویس ردیاب نهنگ؛ پیش‌فرض به سرویس مرتبط Railway متصل است
- `ENABLE_OPPORTUNITY_RESEARCH=true`: پایش خبرها و سیگنال‌های عمومی؛ در صورت فعال بودن `ENABLE_SCHEDULER`

## پرداخت و درآمدزایی
خدمات دیجیتال فروشی داخل تلگرام از Telegram Stars با واحد `XTR` استفاده می‌کنند. ربات برای هر سفارش payload یکتا می‌سازد، مالک سفارش و مبلغ را در SQLite ذخیره می‌کند، پیش‌پرداخت را اعتبارسنجی می‌کند و فقط پس از دریافت `successful_payment` رسید معتبر، خدمت را تحویل می‌دهد. برای فعال‌سازی فروش، قیمت‌های Stars را در Railway تعیین کنید؛ مقدار صفر فروش آن محصول را خاموش نگه می‌دارد.

فرمان‌های فروش: `/premium` برای اشتراک ۳۰روزه، `/businessidea` برای ایده اختصاصی و `/funpack` برای بسته سرگرمی ۱۰سؤالی. فرمان `/paysupport` مسیر رسیدگی به مشکلات پرداخت است. فرمان `/ideas` کاتالوگ ایده‌های دارای نشانه تقاضا را نشان می‌دهد. برای حمایت رمزارزی، کاربر `/donate BTC 0.001` را می‌فرستد و پس از انتقال، `/tx شناسه TXID` را ثبت می‌کند؛ ربات رسید را خصوصی برای مدیر می‌فرستد و مدیر با دکمه تأیید/رد بررسی می‌کند. ربات TXID را خودکار اعتبارسنجی نمی‌کند و مدیر باید تراکنش را در اکسپلورر شبکه بررسی کند. این حمایت اختیاری است و هیچ اشتراک یا خدمت دیجیتالی را فعال نمی‌کند؛ فرمان `/support` آدرس‌های عمومی را نمایش می‌دهد. XRP حتماً به Destination Tag نیاز دارد.

ربات هیچ کلید خصوصی، seed phrase یا اختیار برداشت را ذخیره نمی‌کند. لینک `/wallet` فقط ربات کیف پول مشخص‌شده را باز می‌کند و به معنی اتصال API یا امضای تراکنش نیست. برای اتصال واقعی Wallet Pay به اطلاعات پذیرنده و دسترسی رسمی API نیاز است.

## به‌روزرسانی و انتشار
GitHub Actions وابستگی‌ها و تست‌ها را بررسی می‌کند. Dependabot به‌صورت هفتگی برای وابستگی‌های Python و GitHub Actions پیشنهاد به‌روزرسانی می‌سازد. سرویس Railway به شاخه `main` متصل است و پس از push/ادغام، در صورت فعال بودن GitHub Autodeploy، استقرار خودکار انجام می‌دهد. به‌روزرسانی‌ها بعد از عبور از CI و بازبینی ادغام شوند.


## پژوهش چندبازاری و موتور فرصت‌یابی خودکار

- فایل market_universe.json فهرست ۳۷ بازار مالی و غیرمالی را نگه می‌دارد؛ از رمزارز، سهام، ارز، کالا و اقتصاد کلان تا نرم‌افزار، تجارت آنلاین، کشاورزی، گردشگری، خدمات محلی، انرژی و تولید.
- opportunity_research.py خبرها و سیگنال‌های عمومی را از RSS خبرهای Google و API عمومی Hacker News جستجو می‌کند، آن‌ها را بر اساس تازگی و ارتباط موضوعی مرتب می‌کند و در همان SQLite متصل به volume دائمی ذخیره می‌کند.
- فرمان‌ها: /markets، /opportunities، /marketsearch عبارت. مدیر می‌تواند /refreshideas را اجرا کند.
- پایش خودکار روزانه حدود ساعت ۰۷:۱۵ تهران، به‌علاوه یک اجرای اولیه پس از راه‌اندازی انجام می‌شود. خلاصه فرصت‌های تازه فقط به مدیر ارسال می‌شود؛ انتشار در کانال و گروه همچنان نیازمند تأیید دستی است.
- اتصال ردیاب نهنگ‌ها فقط‌خواندنی است: /whalestatus و /whalealerts داده‌های API سرویس جداگانه را می‌خوانند؛ توکن تلگرام بین دو سرویس به اشتراک گذاشته نمی‌شود.
- ایده‌های تولیدشده با هوش مصنوعی، همراه با URL منابع و زمان تولید، در SQLite پایدار ذخیره می‌شوند و از /opportunities قابل بازیابی‌اند.
- رتبه داخلی موتور صرفاً اولویت نمایش خبر است؛ شاخص دقیق حجم جستجو، احتمال موفقیت یا پیش‌بینی سود نیست. خبرها ممکن است تبلیغاتی یا نادقیق باشند و قبل از تصمیم باید منبع اصلی و مشتری واقعی بررسی شوند.
- پوشش چندبازاری به معنی دسترسی به قیمت زنده همه دارایی‌ها نیست. قیمت زنده فعلی همچنان محدود به نمادهای تعریف‌شده در Binance Spot است؛ سایر حوزه‌ها برای پژوهش خبر و فرصت پوشش داده می‌شوند.
- فعالیت‌های ممنوع یا پرریسک مانند کلاهبرداری، فیشینگ، بدافزار، مواد مخدر، سلاح، قمار، جعل، اسپم، نقض حق نشر و دور زدن مقررات حذف می‌شوند. حوزه‌های تخصصی نیازمند صلاحیت و مجوز معتبر هستند.

## استقرار
سرویس باید روی Railway یا میزبانی دارای اجرای دائمی Python، HTTPS و volume پایدار اجرا شود. کانتینر به‌صورت non-root اجرا می‌شود. آدرس سلامت: `/health`.

## محدودیت‌های داده و ریسک
داده‌ها از API عمومی اسپات دریافت می‌شوند. تیکر عمومی حجم خرید در برابر فروش را به شکل قطعی تفکیک نمی‌کند و به‌تنهایی جریان سفارشات، داده‌های درون‌زنجیره‌ای یا هویت نهنگ‌ها را نشان نمی‌دهد. این ربات ابزار اطلاعاتی است، نه مشاور سرمایه‌گذاری.
