# ربات تحلیل و انتشار گزارش بازار

نسخه اولیه برای دریافت داده عمومی بازار اسپات، ساخت پیش‌نویس و انتشار تلگرام فقط پس از تأیید مدیر.

## قابلیت‌های فعلی
- API سلامت در `/health`
- قیمت، تغییر ۲۴ساعته، حجم مظنه و کندل‌های یک‌ساعته Binance Spot
- میانگین متحرک ساده ۲۰ ساعته
- دستور تلگرام `/draft` برای ساخت پیش‌نویس
- انتشار با تأیید مدیر و فهرست مجاز شناسه‌های مدیر
- محدودیت نرخ درخواست، اعتبارسنجی secret وب‌هوک و هدرهای امنیتی
- آماده‌سازی اجرا با Gunicorn و Docker

## اجرای محلی
1. Python 3.12 نصب کنید.
2. `python -m venv .venv` و محیط مجازی را فعال کنید.
3. `pip install -r requirements.txt`
4. `.env.example` را به `.env` کپی و مقادیر واقعی را فقط در محیط امن وارد کنید.
5. `python app.py`
6. بررسی سلامت: `http://localhost:8000/health`

## تنظیم متغیرهای محیطی
- `TELEGRAM_BOT_TOKEN`: توکن ربات
- `TELEGRAM_CHAT_ID`: شناسه مقصد انتشار گزارش
- `TELEGRAM_ADMIN_IDS`: شناسه عددی مدیران، جداشده با کاما
- `TELEGRAM_WEBHOOK_SECRET`: رشته تصادفی محرمانه
- `BINANCE_BASE_URL`: به‌صورت پیش‌فرض API عمومی بایننس

توکن و رمز واقعی را در کد، مخزن یا پیام عمومی ثبت نکنید. از GitHub Actions Secrets یا Environment میزبان استفاده کنید.

## وب‌هوک تلگرام
آدرس وب‌هوک باید HTTPS باشد و به `https://YOUR_HOST/telegram/webhook` اشاره کند. هدر `X-Telegram-Bot-Api-Secret-Token` باید برابر `TELEGRAM_WEBHOOK_SECRET` باشد. در نسخه فعلی مسیر callback جداگانه نیز وجود دارد؛ برای استفاده از دکمه‌های تأیید، رویدادهای callback باید به مسیر `/telegram/callback` هدایت شوند یا منطق آن در مسیر مشترک وب‌هوک ادغام شود.

## موارد تکمیل‌نشده
- زمان‌بندی خودکار ۰۸:۰۰، ۱۲:۰۰، ۱۶:۰۰ و ۲۱:۰۰
- ذخیره پایدار پیش‌نویس‌ها؛ فعلاً RAM است و با راه‌اندازی مجدد پاک می‌شود
- نمودار تصویری و گزارش کامل تکنیکال
- منبع داده معتبر طلا، نفت و فارکس
- کانال‌های انتشار پیام‌رسان‌های داخلی
- تست یکپارچه و استقرار عملیاتی

حجم خرید و فروش تفکیک‌شده از تیکر عمومی قابل استنتاج قطعی نیست و در این نسخه جعل یا تخمین زده نمی‌شود.

## استقرار
این برنامه به میزبان Python با پشتیبانی از اجرای دائمی Gunicorn، متغیرهای محیطی و HTTPS نیاز دارد. هاست اشتراکی PHP ممکن است اجرای دائمی پردازش Python را پشتیبانی نکند؛ قبل از استقرار باید قابلیت Python App، SSH و پردازش پایدار بررسی شود. این نرم‌افزار توصیه قطعی خرید یا فروش ارائه نمی‌کند.
